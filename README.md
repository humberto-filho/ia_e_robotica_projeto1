# Path planning em robótica

Projeto desenvolvido para a disciplina de **Inteligência Artificial e Robótica**.

O objetivo do projeto é implementar um algoritmo de **path planning utilizando A\*** para permitir que um robô encontre um caminho entre um ponto inicial e um objetivo, considerando obstáculos, regiões desconhecidas e a distância das paredes.
